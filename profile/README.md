# kiz-lang

This is the kiz-lang organization,
dedicated to the development of the Kiz programming language.

Projects

- kizi: Compiler and virtual machine for the Kiz language
- kiz-lang-doc: Official standard documentation
- kiz-lang-playground: Online interactive playground
- kiz-lang-vscode: VS Code extension for Kiz
- kiz-lang-website: Official website and homepage
- kiz-code-style: Modern C++ code style guide
- ks-lib: Modern C++ utility library with modern class abstractions
- utf8string-lib: Lightweight UTF-8 string library for modern C++
